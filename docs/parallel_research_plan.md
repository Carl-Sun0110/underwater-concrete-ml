# 双轨研究实施方案（2026-10-23）

本方案取代“必须全部核实且输入完整才能训练”的开发顺序。旧审计主档与实验保留为历史版本；它们的严格门槛不约束本探索入口。所有结果必须标注探索性质，不能据此自动升级正式可靠状态。

## 最小可行实验

1. 读取现有458条暂定换算标签候选，不重新编辑Excel。原始Total含1082条；458不是全部可信样本，也不是全部可能可训练记录。未进入旧候选的其他记录留待下一数据版本分析，并非全部判为D。
2. 输入允许未知。Water/Cem非正数视为未知；可选材料原始0可能是未掺或未记录，主实验视为未知，另设“原值照录”敏感性实验。不补抗压标签，不删除高强度记录，不通过未知密度推算绝对用量。
3. 默认B：原表论文身份明确、测量强度和用户许可暂定换算可用，但尚未完整核查。已知非直接水下成型的Assaad记录为C，单独比较AB与ABC；A须有关键数据证据人工复核，本轮不自动产生A；无来源/无有效标签或矛盾未解为D。本分层只是探索用途，不改变审计主档。“原表有论文名”并不证明每一个值与论文相符。
4. 根据全部458条的论文、研究组及配比签名重新合组；任何历史测试来源整组保留，未使用其目标选模型。313条用于开发，145条留出。此前核心缺失14条此次保留。历史测试曾在早期实验被查看，不能再声称全新盲测。
5. 同一分组五折对照：均值参照、RF、XGBoost；核心2字段、材料12字段、含混合单位外加剂14字段敏感性。每折独立标准化与中位数/距离加权KNN插补，附缺失指示器。完全未知列仅数值填0，含义仍是未知，不能当作物理上未掺。
6. 固定模型参数，不先做大规模调参。报告MAE、RMSE、R²、各折、各论文组平均误差及折外逐条误差。AB与ABC共用分组折，另输出相同AB验证样本的指标，区分增加C训练记录的影响与测试群体改变。
7. 预先规定主要候选为AB、核心/材料字段、零值未知。混合单位外加剂和零值照录只作敏感性；不因为它们的分数好就认定单位问题解决。按主要候选CV MAE选择演示模型，保存开发集拟合文件。相同CV既选模又报告有选择偏差，需要后续嵌套验证及新独立验证。
8. 用验证折置换重要性和训练折外误差寻找下轮核查重点；SHAP解释为模型关联，不能解释为因果或证据真实性。

## 后续顺序

- 并行A：沿用已有文献证据提取程序，小批更新来源、表号页码、测量标签、换算依据、单位、零值语义。优先核查折外误差高且影响多样本的论文；无需先补齐全部论文。不自动接受未经核验的Agent推断。
- 并行B：先完成本次固定参数基线；下一轮训练折内分组调参，加入CatBoost以及老师要求的SVR/MLP对照。比较配合比无量纲比值、同一单位的外加剂输入、已核实标签子集与来源明确未逐项核查子集。
- 数据版本：每次生成新快照及输入哈希、配置、代码与环境版本；保留旧结果。质量变更在配置quality_overrides列出sample_id、grade、reason和evidence，纠正标签要生成有依据的新标签版本，不能仅改等级。
- 评估数据改进：尽可能保留同样的外层分组及共同验证记录，比较数据版本变化；把特征变化、样本变化和标签纠正分开实验，不通过删除难预测记录制造提升。

## 必须保留的问题

换算系数仍是用户许可暂定值；密度假设和部分单位未知；可选材料零值含义混杂；部分论文原文未到位；同文献样本相关且不同体系差异大；完整配比签名不能保证识别所有近似重复。它们影响结果解释和优先核查次序，但不阻止本探索实验。

## 运行

在仓库根目录：

```bash
PYTHONPATH=src /workspace/.venv-underwater-ml/bin/python scripts/run_parallel_exploration.py --output outputs/parallel-exploration-v1
PYTHONPATH=src /workspace/.venv-underwater-ml/bin/python -m unittest discover -s tests -v
MPLCONFIGDIR=/tmp/underwater-concrete-plot-cache/matplotlib PYTHONPATH=src /workspace/.venv-underwater-ml/bin/python scripts/explain_parallel_exploration.py
```

输出目录须为新目录。默认配置configs/parallel_exploration_v1.json。数据路径仍指当前附件目录，迁移环境时须调整路径并检查哈希。Python 3.12，安装依赖`python -m pip install -r requirements-exploration.txt`。SHAP解释不依赖PyTorch，无需先安装大型神经网络依赖。
